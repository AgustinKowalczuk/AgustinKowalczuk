## 🚀 Proyecto destacado

### [MK Cars — Landing page](https://github.com/AgustinKowalczuk/Mk-LandingPage) · [Demo en vivo](https://mk-cars.vercel.app/)

Sitio responsive para un taller de chapa y pintura automotriz, con formulario de contacto funcional y acceso directo a WhatsApp.

- **Formulario con envío de correos** mediante Resend y plantillas de React Email.
- **Protección contra spam:** validación en servidor, campo honeypot y límite de 5 solicitudes por IP cada 10 minutos (Upstash Redis).
- **Stack:** Next.js 16 (App Router), React 19, TypeScript y Tailwind CSS 4, desplegado en Vercel.
- Documentación completa en [español](https://github.com/AgustinKowalczuk/Mk-LandingPage#readme) e [inglés](https://github.com/AgustinKowalczuk/Mk-LandingPage/blob/main/README.en.md).
