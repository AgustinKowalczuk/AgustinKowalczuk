## 🚀 Featured project

### [MK Cars — Landing page](https://github.com/AgustinKowalczuk/Mk-LandingPage) · [Live demo](https://mk-cars.vercel.app/)

Responsive website for an auto body and paint shop, with a working contact form and a direct WhatsApp link.

- **Contact form with email delivery** using Resend and React Email templates.
- **Spam protection:** server-side validation, honeypot field and a limit of 5 requests per IP every 10 minutes (Upstash Redis).
- **Stack:** Next.js 16 (App Router), React 19, TypeScript and Tailwind CSS 4, deployed on Vercel.
- Full documentation in [Spanish](https://github.com/AgustinKowalczuk/Mk-LandingPage#readme) and [English](https://github.com/AgustinKowalczuk/Mk-LandingPage/blob/main/README.en.md).
